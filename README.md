
# Space X 
![Spacex](https://github.com/user-attachments/assets/a1557cdd-6fd2-482a-9e3f-75b7640ab112)
## Descrição

Space X é uma landing page temática espacial criada como projeto para o curso da EBAC. O site apresenta informações sobre órbita terrestre, tecnologia de satélites, exploração espacial e conceitos relacionados à astronomia, tudo em um design moderno e responsivo.

O projeto utiliza HTML, CSS e fontes personalizadas para garantir uma experiência visual agradável e organizada, com seções que facilitam a navegação e o entendimento dos conteúdos espaciais.

## Funcionalidades

- Navegação por ancoras em diferentes seções: Sobre, Tecnologia, Galáxia e Satélites.
- Layout responsivo e moderno.
- Conteúdo informativo sobre astronomia, satélites e exploração espacial.
- Uso de imagens e ícones para complementar o texto.
- Botões interativos para melhorar a experiência do usuário.

## Tecnologias Utilizadas

- HTML5  
- CSS3  
- Google Fonts (IBM Plex Mono, Plus Jakarta Sans)  
- Ícones personalizados  
- Design responsivo
